FetchFlow Download Manager August 2026 Policy Standards

Privacy Policy

Last updated: August 2026

FetchFlow Download Manager (Wayland & Desktop Edition), developed by Mayanktaker Computers & Web Development, is committed to protecting user privacy. This Privacy Policy details our handling of information across the FetchFlow desktop application, companion browser extensions, and official website.

1. Zero Telemetry & No Cloud Tracking

FetchFlow is fully open-source software (licensed under GNU GPL v3.0). It contains zero tracking components, zero telemetry, zero analytics scripts, and zero spyware. We do not collect, store, sell, or transmit any personally identifiable information, browsing histories, search queries, or downloaded file records to any cloud server or third party.

2. FetchFlow Browser Helper (Chrome & Firefox Extensions)

The FetchFlow Browser Helper browser extensions for Google Chrome, Mozilla Firefox, and Chromium-based browsers operate strictly as a local integration bridge between your browser and the FetchFlow desktop client:

  • Local Loopback Communication: The browser extension communicates exclusively with the FetchFlow desktop application running on your own machine via local loopback (127.0.0.1 / ws://127.0.0.1:8597). No data is sent over the Internet to any third-party or developer server.
  • Download Metadata: When you initiate a download or capture a media stream, the extension passes the download URL, file name, referrer URL, and necessary session headers/cookies directly to your local desktop client to facilitate multi-threaded accelerated downloading.
  • Local Storage: All download histories, configuration rules, and categories remain entirely on your local filesystem in an encrypted or local SQLite database and are never shared.

3. Compliance with Extension Store Policies

In compliance with the Google Chrome Web Store Limited Use Requirements and Mozilla Add-on Data Collection Policies:

  • Data collected by the extension is restricted strictly to the user-facing purpose of download management.
  • User data is never sold to data brokers, advertising platforms, or third parties.
  • User data is never used or transferred for personalized advertising, credit assessment, or user profiling.

4. Unsolicited Advertising

FetchFlow and its companion extensions are 100% ad-free. The software does not inject ads, display promotional popups, or bundle third-party promotional installers.

5. External Links

The FetchFlow application and website may contain links to external project repositories or documentation pages. We do not control and are not responsible for the privacy practices of external third-party websites.
